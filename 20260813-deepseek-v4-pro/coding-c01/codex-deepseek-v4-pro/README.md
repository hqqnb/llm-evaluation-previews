# 《极光》星舰 · 3D 交互还原

金·斯坦利·罗宾逊科幻小说《极光》（*Aurora*，2015；中译本 2020 重庆出版社）中那艘驶向天仓五（Tau Ceti）的世代飞船，用 Three.js 做的可交互 3D 还原。

**小说里的这艘船**：2545 年从土星轨道出发，载约 2122 人，以约 1/10 光速航行 170 年，目标是天仓五的宜居卫星“极光”。船体是一根 **10 公里长的主轴（spine）**，上面套着两个**对向旋转**的生态环：每环由 **12 个生态舱**相接而成（舱直径 1 公里、长 4 公里，30° 相接、舱间闸门两端各斜置 15°），靠旋转产生 **0.83g** 重力；每个外环经**六根辐条**连到主轴，环 A 承载“旧世界”生态、环 B 承载“新世界”生态。舰载量子 AI 被总工程师德维昵称为“波琳”（Pauline）。

## 运行方式

项目是**零构建**的静态网页（Three.js r160 已本地化到 `vendor/`，可离线运行）。ES Module 不能直接以 `file://` 打开，需要任意静态服务器：

```bash
# 方式一：一键脚本（自动开浏览器）
./start.sh

# 方式二：Python 自带服务器（macOS/Linux 均有 Python 3）
python3 -m http.server 8000

# 方式三：Node
npx serve .
```

然后打开 **http://localhost:8000**。需要支持 WebGL 的现代浏览器（Chrome / Edge / Safari / Firefox 最新版均可）。

## 操作说明

**飞船外观（默认视图）**

- 左键拖拽：360° 环绕飞船；右键拖拽：平移；滚轮 / 双指：放大缩小
- 悬停任意部件查看名称与设定说明；**点击生态舱**直接进入其内部
- 左侧“船体部件”面板可一键聚焦主轴、环 A/B、舰桥、发动机、减速磁场
- 底部控制条：展开“减速磁场（Decel）”、切换环转速（演示/真实/慢速）、调节航行速度

**生态舱内部（点击画面锁定鼠标）**

- WASD 移动（Shift 疾走），鼠标环顾；走到两端闸门，门会自动开启并穿越到相邻生态舱
- 右侧面板可跳转全部 **24 个生态舱**（环 A 旧世界 / 环 B 新世界），或进入主轴内部
- ESC 释放鼠标，再点击画面重新锁定

**主轴内部（零重力）**

- WASD 漂浮移动，Shift 加速/上浮，Ctrl 下潜
- J 直达舰桥（舷窗可见天仓五与“极光”行星）、K 直达量子核心“波琳”、L 直达发动机舱

快捷键：`1` 回外观，`2` 进舱内，`3` 进主轴。

## 还原说明（诚实地讲）

- **严格按原著数据建模**：主轴 10 km；双环对旋；每环 12 舱 ×（直径 1 km、长 4 km）；环直径约 15.3 km；30°/15° 闸门；六辐条；0.83g；聚变推进 + 土星激光助推 + 磁场/引力弹弓减速（返航时外壳“先暗红、继而发亮”）；舰桥在主轴前端；AI 核心“波琳”；环 B + 主轴为返航船体。
- **合理演绎的部分**（原著未逐件描写）：生态舱采光面朝向主轴（昼夜光带）、发动机喷口造型、内结构环半径、舱内农庄/树木等细节、环 A/B 的前后位置。应用内“设定依据”面板对每一条都标注了“原著设定 / 合理演绎”与出处。
- 舱室名单（24 个）依据 kimstanleyrobinson.info 的《Aurora》设定页整理：环 A 含塔斯马尼亚、喜马拉雅、长江、西伯利亚、伊朗、蒙古、欧亚草原、巴尔干、肯尼亚、孟加拉、印度尼西亚、北海道；环 B 含新斯科舍、内华达山脉、大草原、拉布拉多、潘帕斯、索诺拉、皮埃蒙特(?)、哥斯达黎加、亚马逊、奥林匹亚、巴塔哥尼亚及一个资料未载明的第 12 舱（界面中如实标注）。

## 测试说明

仓库自带两套无头浏览器自动化测试（`test/`，需 Node 18+ 与 Chrome）：

```bash
cd test
npm install                 # 安装 playwright-core 与 pngjs
node smoke.js               # 截图回归：10 个场景（外观/环/发动机/磁帆/4 个生态舱/主轴）
node probe3.js              # 交互逻辑：帧率采样、滚轮缩放、舱内行走、闸门穿越、主轴漂浮
node analyze.js shots/xx.png  # 像素统计工具（亮度/色相分布，用于黑屏与画面回归）
```

结果判定：

- `smoke.js` 每个场景打印 `OK`，结尾 `ERRORS: NONE`；截图输出到 `test/shots/`
- `probe3.js` 各项打印 `PASS`，结尾 `ERRORS: NONE`
- 若本机 Chrome 不在默认路径，用 `CHROME_PATH=/path/to/chrome node smoke.js` 指定

注意：无头 Chrome 使用软件渲染（SwiftShader），`probe3.js` 报出的帧率不代表真实 GPU 性能；连续截屏偶尔触发软件渲染器黑帧，脚本已内置黑帧自动重试。

## 文件结构

```
index.html          页面与 UI 骨架
css/style.css       界面样式
js/main.js          渲染器 / 模式切换 / 轨道控制 / 拾取 / 主循环
js/config.js        小说设定数据（尺寸、24 舱名单、生态参数、部件说明）
js/stars.js         深空背景（星空、银河、星云、恒星、流星、航速尘埃）
js/exterior.js      飞船外部模型与动态（双环对旋、尾焰、减速磁场、航行灯）
js/interior.js      舱内探索（曲面行走、程序化生态、闸门穿越、零重力主轴）
js/ui.js            面板 / HUD / 提示 / 设定依据
js/utils.js         噪声、随机、参数曲面与纹理工具
vendor/             本地化的 three.js r160（含 OrbitControls、BufferGeometryUtils）
test/               自动化测试与截图工具
```
