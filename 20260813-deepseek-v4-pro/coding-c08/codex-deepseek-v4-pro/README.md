# STRIKE ZONE — 浏览器战术爆破 FPS

一款完整可玩的《Counter-Strike》风格第一人称战术射击游戏。纯浏览器运行，无构建步骤，零外部资源依赖（Three.js 已本地化，贴图/音效全部程序化生成，可离线游玩）。

## 快速开始

需要 Node.js（可选）或 Python 3。由于浏览器 ES Module 限制，不能直接双击 `index.html`，需通过本地 HTTP 服务访问：

```bash
# 方式 A（Node）
node server.js
# 打开 http://127.0.0.1:8123

# 方式 B（Python）
python3 -m http.server 8123
# 打开 http://127.0.0.1:8123

# 方式 C（任意静态服务器均可，如 VS Code Live Server）
```

推荐使用 Chrome / Edge 等 Chromium 内核浏览器，桌面端全屏游玩。

## 内容

**三张完整爆破地图**

- **沙漠之镇 II**（Dust2 复刻）：T 出生点、CT 出生点、A 包点、B 包点、中路、A 大、A 小、A 坑、A 斜坡、中门（双门）、Xbox、B 洞（高/低洞）、B 门、B 平台、警家、长门、箱体掩体、狙击对枪线、下包点位、防守架点、进攻路线、回防路线与绕后路线一应俱全，攻防节奏、交火距离与控图逻辑贴近经典 Dust2。
- **熔铸厂**（工业厂房）：A 点在带二层夹层的厂房内（垂直立体 + 近距离），B 点在开阔货场（集装箱长线对枪），节奏与 Dust2 完全不同。
- **地下铁**（地铁站）：A 点为长站台（列车作长线掩体），B 点为维护隧道（贴身近战），另有二层票务大厅的垂直元素。

**玩法系统**

- 第一人称视角、鼠标控制、WASD、跳跃、下蹲、静步
- 9 把枪械（Glock-18 / USP-S / 沙漠之鹰 / MAC-10 / MP9 / P90 / AK-47 / M4A4 / AWP / Nova）+ 战术刀 + 高爆手雷 / 闪光弹 / 烟雾弹 / 燃烧瓶
- 后坐力模式、散布、移动精度惩罚、开镜、爆头、护甲与头盔、死亡观战与回合重生
- 经典爆破模式：下包、守包、拆包、40 秒炸弹倒计时、回合时间与胜负判定
- 完整经济系统：起始 $800、击杀奖励（按武器）、回合胜负奖励、连败补偿、下包奖励、保枪、掉枪拾取
- 购买菜单：武器 / 防弹衣 / 头盔 / 拆弹器 / 投掷物
- HUD：雷达（含 C4 标记）、准星、命中反馈、血量 / 护甲 / 弹药 / 金钱 / 回合时间 / 比分 / 击杀提示 / 伤害方向指示
- 程序化音效：枪声、脚步、换弹、爆炸、下包 / 拆包提示音、回合音效、环境音
- Bot AI：分路进攻（A 大 / A 小 / 中路 / B 洞）、分点防守、中路控图、夹击、回防、下包、拆包、投掷物使用（烟中门、闪点、火烧平台、雷清点）、听声辨位、残局决策
- 四档难度（简单 / 普通 / 困难 / 专家）：反应速度、瞄准精度、开火节奏、投掷物与战术选择、地图控制逐级提升
- 主菜单可配置：3 张地图、阵营（T / CT / 随机）、每队 Bot 数（1–5）、难度、胜利回合数（4 / 8 / 13）
- 暂停、重新开始、计分板、对局结算与 MVP、再来一局

## 测试

项目附带基于 Puppeteer + Chrome 无头模式（SwiftShader 软件渲染）的自动化测试：

```bash
npm install          # 安装 puppeteer-core（仅测试用）
npm test             # 跑全部冒烟 + 玩法 + 炸弹链路测试
```

测试覆盖：

- `test/smoke.mjs` — 加载、开局、购买、回合推进、三张地图切换、控制台零错误
- `test/gameplay.mjs` — 命中判定（胶囊体/爆头）、手雷伤害、整局模拟（击杀、比分、结算）、三图 AI 对战
- `test/bomb.mjs` — 下包→爆炸→T 胜链路
- `test/defuse.mjs` — 拆包→CT 胜链路
- `test/perf2.mjs` — 软件渲染帧率下限（真机 GPU 性能远高于此）
- `test/shots.mjs` / `test/ui-check.mjs` — 视觉 QA 截图（第一人称、购买菜单、计分板、暂停菜单、开镜）

注：无头模式使用 CPU 软件渲染，10 FPS 属正常下限；在真实 GPU 的桌面浏览器上通常可达 60 FPS 以上，游戏内置自适应画质（低帧率自动降像素比/阴影）。

## 技术要点

- 地图为体素式 AABB 世界：墙体/箱体使用 InstancedMesh 合批，碰撞使用空间哈希网格
- Bot 导航：0.6m 网格 + 目标距离场（Dijkstra BFS 缓存）+ 直线可行性捷径，支持坡道、台阶、高低差与跳下惩罚
- 命中判定：射线 vs 身体胶囊 + 头部球，护甲/头盔/部位倍率按 CS 规则折算
- 投掷物：抛物线 + 墙体反弹（燃烧瓶碰撞即碎），烟雾弹有真实遮挡（AI 视线同样被挡）
- 音效、贴图、模型全部运行时程序化生成，无需外部素材
